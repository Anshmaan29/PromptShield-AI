# Product
## Platform
Web.
## Users and purpose
Developers and students preparing authorized prompt-injection tests for chatbots. The first prototype helps prepare test and review prompts for use in an external AI model.
## Constraints
No confidential inputs or API credentials. A manual model workflow is used; no claim of automated target testing or safety guarantees.
## Evidence
Milestone 1 proposal and baseline prompt supplied by the team. No prior implementation was supplied.
